## Recurring defects (do not replicate)

1. Phone number merged into "92% Response Rate" text; "Call Us:" blank on most pages.
2. "Thanks for Contacting Us." / "Your Enquiry has been sent successfully." printed in static content before any submission.
3. One French-door description reused on ~15 unrelated products.
4. Spec tables contradict product names (fixed/swing/hinged doors listed as "Sliding").
5. Duplicate categories (Aluminum/Aluminium Window; two installation pages; sliding door twice).
6. Location-keyword product entries for cities the business uses only as keywords.
7. og:image dimensions wrong on most pages; invalid `meta-Content-Type` tag.
8. Inconsistent spelling: UPVC/Upvc/uPVC, Aluminum/Aluminium, "Prominance".
